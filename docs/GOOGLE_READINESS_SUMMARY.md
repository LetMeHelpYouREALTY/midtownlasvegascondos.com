## 🚀 What You Need to Do (15 minutes)

### 1. Add Google Search Console Verification (5 min)

**In Vercel:**
1. Go to your project → Settings → Environment Variables
2. Add new variable:
   - **Name**: `NEXT_PUBLIC_GOOGLE_SITE_VERIFICATION`
   - **Value**: [Get this from Google Search Console - see setup guide]
3. Save and redeploy

**In Google Search Console:**
1. Go to https://search.google.com/search-console
2. Add property: `https://www.midtownlasvegascondos.com`
3. Choose HTML tag verification method
4. Copy the verification code
5. Add it to Vercel (as above)
6. Redeploy and verify

### 2. Submit Sitemap (2 min)

1. In Google Search Console, go to **Sitemaps**
2. Enter: `sitemap.xml`
3. Click **Submit**
4. Wait 24-48 hours

### 3. Request Indexing (8 min)

1. Go to **URL Inspection** tool
2. Request indexing for these 5 key pages:
   - `/`
   - `/midtown-real-estate`
   - `/investment-properties`
   - `/buyers-guide-midtown`
   - `/arts-district-guide`
